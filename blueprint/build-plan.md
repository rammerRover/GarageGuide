# Build Plan

Features are listed in implementation order. The current app scaffold,
connectivity screen, health endpoints, and PostgreSQL schema are pre-build
foundation, not completed product features.

## Your features

- [ ] 1. Account registration, sign-in, sign-out, and secure private sessions.
- [ ] 2. Create and manage vehicles with current mileage and/or operating hours.
- [ ] 3. Record and review dated service history for each vehicle.
- [ ] 4. Create recurring maintenance schedules and calculate upcoming, due, and
  overdue status from dates and available readings.
- [ ] 5. Complete one or more maintenance schedules by linking them to a service
  record.
- [ ] 6. Search the curated parts catalog and show only verified vehicle fitments.
- [ ] 7. Save catalog parts or manually entered parts to a vehicle.
- [ ] 8. Record parts used by a service while preserving historical part details.
- [ ] 9. Summarize known service costs per vehicle and keep unknown costs distinct.
- [ ] 10. Build a garage dashboard with vehicle status, service history, maintenance
  status, and calculated in-app reminders.
